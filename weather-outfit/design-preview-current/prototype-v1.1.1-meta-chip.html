핵심 결정 — Claude 무드 텍스트는 화면에서 제거

왜: mood_tag 는 Claude가 추천마다 자유 생성 → 단어가 매번 바뀌고 추상적이라 사용자가 "이게 뭘 뜻하지?" 함. 화면 토큰은 결정적이고 사용자가 이미 아는 값이어야 함. → moodTag는 envelope에 보존(통계·v1.5 캘린더)하되 메인 칩에선 미노출.

변형칩장점 / 주의
A (권장)성별 · 계절가장 명확 — 결정적 2토큰. Claude 텍스트 0 / 다소 단출
B성별 · 테마 · 계절테마=사용자 선택값(이해함) / 테마 라벨이 무드단어라 '여름' 옆에서 약간 모호
C(칩 제거)헤더(날씨+캡션)가 이미 충분 / 컨텍스트 태그 사라짐

토큰 출처: 성별=gender(프로필) · 계절=season(이미 envelope, enum→한글) · 테마=preferred_theme(사용자 선택). 전부 결정적 — Claude 자유생성 0.

기존 API v1.0.0 영향 = 비파괴: A/B/C 모두 season(기존 필드) + 프로필값만 사용, envelope 스키마 변경 0. mood_tag 는 그대로 두고 화면에서만 안 씀 → 옛 클라 영향 0.

client = 칩 재배치 + season enum→한글 (server 작업 불필요). 시각 검증용 — 명세 SoT는 wireframes.md.
