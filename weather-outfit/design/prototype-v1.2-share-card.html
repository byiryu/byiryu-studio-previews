PALETI · 오늘의 룩 공유 카드 (v1.2 신규 피처)

지금 추천 envelope(palette + 옷종류 + 배색(scheme) + 날씨 + 위치·날짜 + 캡션 + 무드/계절)를 SNS 공유용 카드로. "색상만이라 부족할까?" 판단용 — 변형 A/B/C 비교. 실제 옷 비주얼(AI 코디 이미지)은 v1.3 업그레이드(이 카드가 그 surface).
※ 카드 비율 = 4:5 (인스타 피드/스토리). 워터마크 = 무예산 성장 루프
A · 미니멀 스와치 가장 가벼움
팔레트가 주인공. 색·옷종류·배색만 큼직하게. 제작 가장 빠름. 깔끔하지만 정보 밀도 낮음.
B · 아이콘-리치 정보형
옷종류 아이콘 + 날씨 아이콘 + 칩. "무슨 옷·어떤 날씨"가 한눈에. 아이콘 에셋(소) 필요. 다소 빽빽.
C · 무드 에디토리얼 공유각 ★
캡션(스토리)이 히어로 + 무드 기반 배경 톤. 매거진 느낌 = 공유 욕구 최대. AI 이미지(v1.3) 들어가면 이 레이아웃이 자연 확장.

판단 포인트 — "색상만이라 부족한가?"

카드에 실제로 들어가는 건 색 팔레트(한국어 색이름) + 옷종류 + 배색방식(톤온톤/보색…) + 날씨 + 위치·날짜 + 캡션(Claude 문장) + 무드·계절 + 브랜딩 — 색 스와치만이 아님. 그래도 "옷의 실제 모습"이 없는 건 사실 → 아래 2단 설계로 흡수.

변형강점주의 / 노력
A 미니멀가장 빠름·깔끔·팔레트 강조정보 밀도 낮음 — "색만" 인상에 가장 취약
B 아이콘옷종류·날씨 한눈 / 정보 풍부아이콘 에셋(라인 5종) 필요·다소 빽빽
C 에디토리얼공유각 최대·스토리·무드 톤 / AI이미지 surface캡션 길이 가변 대응·배경 톤 로직

2단 설계: v1.2 = 비AI 에디토리얼 카드(server 0, client 렌더→이미지+공유 시트). v1.3 = image_url(AI 코디 이미지)를 카드 히어로로 = 옷 실제 비주얼. 지금 카드가 그 자리(surface). → 지금 당기면 cost/scope, 미루면 자연 업그레이드.

좋싫 1탭은 별건(메인 추천에 👍/👎 + 피드백 저장 → v2 방향 결정용 데이터). 디자인 부담 없어 같이 v1.2 진입.
