검증 포인트 — 플로우 일관성

paranoia 충족
• #1 메타3요소 = 메인(02)에 영웅 프레즌스·주 CTA 위계·진행 티저 3종 동시 — 현 빌드의 가장 큰 공백 교정.
• #3 터치 인체공학 = 전 화면 주 CTA·덱 슬롯 하단 엄지존 + ≥44pt. 전투(04) 영웅 스킬 = 우측 데드존 분리.
• #5 난전 가독 = 전투(04) 코스트게이지·덱슬롯·HP바를 피드백 토스트가 가리지 않음(키 유닛 캡).
B코어 재설계 3건 반영
• 위협 텔레그래프 2축(03) = "중장갑/마법취약" + 응수 hint. ShowFormation 확장.
• 피드백 정직화(04) = 효과적!/버팀/치명타! 3색 + 물/마 색코딩(텔레그래프 색과 일치).
• 시너지 legibility(03 텍스트 충족도 + 04 HUD 상시 라벨) = 텍스트만. 시너지·위협 아이콘 = 프리즈(시스템 코드 굳기 전 동결).
