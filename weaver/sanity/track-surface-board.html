달리는 표면인가, 아니면 벽인가.

트랙 = 공전 코어의 표면. 캐릭터는 회전 다각형 둘레의 안쪽 면을 벽주행하고, 코어는 인테리어에 떠 있다. 발밑 band 가 "내가 가로질러 달리는 표면"으로 읽혀야 하는데 — unity step-8 의 균일 갈색 밴드는 벽/레인/가드레일로 읽혔다.

동일 게임 1프레임(회전 사각 트랙·리액터 코어·벽주행 캐릭터) 위에 후보 7종. 제작은 unity 절차 셰이더 — 이 보드는 룩 타겟만 정한다(드론 안무 보드 패턴). rim/pulse 존치 후보 · body 재작업.

↳ 무엇이 실패했나 (step-8 baseline)

body 밴드: +Normal 오프셋 · 폭 70 · 알파 0.32 균일 칠. 밝은 주행 엣지선과 평행하게 같은 밝기 띠가 코어 방향으로 깔리니, "표면이 깊이로 후퇴"가 아니라 두 선 사이의 면적 = 벽/채널로 읽힌다. 깊이·표면·모션 단서가 전부 0. → 진단: 평행 띠는 방향감 없는 면적 칠일 뿐, "달림"의 신호가 없다.

01

후보 7종 — "달리는 표면"으로 읽히는가

해법 축 = 깊이(균일→후퇴→베벨) · 표면 마커(없음→진행 수직 트레드→패널 심→센터라인) · 머티리얼(에너지/헐/균열). 각 후보 = 같은 프레임, band 트리트먼트만 교체. 게이트 = 읽힘 의도 부합 · 모션 진행 단서 · 가독 전경 미가림.

02

구역 머티리얼 변주 — 권장 구조에 적용

엣지(주행선)는 구역 무관 항상 동일(게임 앵커·안 꾸밈). body 질감만 구역 테마로 교체 — 같은 "표면" 구조에 머티리얼만. 구역 배정(spec §9.5) = 리액터·네온도시·붕괴 (MVP 컷 3타입).

03

가독 게이트 — 전경을 가리지 않는가 (paranoia #5)

권장안 위에 실제 전경 요소를 얹는다: 머리 위 정답 dot · 동반 드론 · ⚪ 낙하물 · 위협 dot. §9.1.6 = 전경 풀대비 / 표면 저주파·명도↓·후면. 장식이 위협 가독 해치면 거부.

  • ✓
    주행 엣지 = 최고 명도 앵커

    엣지선만 풀 글로우(#EEEEF2 코어 + 카테고리 펄스). body 는 엣지보다 항상 ≥40% 어둡게 → 캐릭터 발밑선이 늘 가장 밝아 "여기가 바닥".

  • ✓
    body 명도 상한 = 코어보다 밝게, 전경보다 어둡게

    표면 휘도 밴드 L 28–46%. 위협 dot·드론·낙하물(L 70%+)과 분리. 표면 채도는 전경 카테고리 4색 회피(앰버/시안/적 = 무채에 가까운 틴트).

  • ✓
    모션은 저주파·표면 한정

    트레드 스크롤은 band 안쪽(코어 쪽)으로 페이드 — 엣지선 위 0px 침범. 깜빡임 X(자동플레이감 회피, 드론/위협 텔레그래프와 구분).

  • ?
    정량 상한 = 기기 렌더 후 잠금

    명도/대비 수치(L·ΔE)는 위협 기기 실렌더 1회 후 확정(§9.1.6 "정량화 = 위협 기기 렌더 후"). 보드 = 구조·상대 위계만.

04

권장 & 잠금 대상

디자이너 권장

구조 = D 베벨 렛지 + E 트레드 합본 · 머티리얼만 구역 교체

왜
  • 베벨 렛지(D) = "내가 솔리드 링 위에 올라서 있다"는 깊이를 단번에 줌 — band 가 평행 띠(벽)가 아니라 두께 있는 단(ledge)의 윗면으로 뒤집힘. 실패의 직접 해독제.
  • 진행 수직 트레드(E) = 스크롤하는 가로 결이 "이 면을 따라 달린다"는 모션을 줌. 정적 띠엔 없던 유일한 "달림" 신호.
  • 둘 다 절차 친화 — 베벨 = 엣지 아래 그라데이션+섀도선, 트레드 = 수직 라인 스크롤. 타일셋 0(임의각 시머 회피, spec §9.3).
  • rim(엣지 림라이트)·pulse(카테고리색)는 존치 — 실패한 건 body 뿐.
확정 시 design-system track_surface 정밀화
  • ① 엣지 = 림라이트 #EEEEF2 코어 2px + 외측 글로우, 구역 무관 고정.
  • ② body = 엣지 아래 L46%→L28% 인워드 그라데이션(베벨) + 코어쪽 끝 1px 섀도선. 폭 ≈ 36(구 70 → 축소, "면적 칠" 탈피).
  • ③ 트레드 = 진행 수직 결, 간격 ~14, 명도 ±8%, band 안쪽 페이드, 스크롤 = 주행 속도 동기.
  • ④ pulse = 활성 카테고리색 엣지 글로우 · 위기(budget==1) 붉게.
  • ⑤ 머티리얼 = 리액터(앰버 헐 패널) / 도시(시안 회로 라인) / 붕괴(적 균열·들뜸) — body 텍스처만 교체, 구조 동일.

↳ 사용자 결정 (택1 + 옵션)

  1. 구조 안 — 권장 D+E 합본 / 또는 단독(D 베벨 / E 트레드 / F 헐패널 / G 에너지 리본 / C 후퇴 그라데이션 / B 림온리).
  2. 트레드 방향감 — 진행 수직 결(권장·"달림" 강함) vs 센터라인+레일(도로감, 더 "트랙") vs 결 없음(미니멀).
  3. 모션 강도 — 스크롤 트레드 on(권장) / 정적(절차 비용↓·차분).
  4. (옵션) AI 무드 레퍼런스 — 확정 구조의 무드 이미지 1~2장 PixelLab/외부 생성 여부(절차 구현 목표 이미지용).
