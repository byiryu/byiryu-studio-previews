weaver · 디자인 세션 · 트랙면 · rev.3 팔레트·패턴 재고

채도는 정보에만. 트랙은 비켜선다.

G 합본 구조(발광 림 + 흐름 + 코어 림)는 확정. rev.3 = 색·패턴·그라데이션을 디자이너 규율로 재정의. 핵심 = weaver는 Downwell 규율(제한 팔레트·색 = 정보). rev.2 가 트랙을 앰버로 발광시킨 건 정보색(🟡🪙) 오염 — 가독 1순위 위반. 트랙은 중립으로 비켜서고, 구역색은 코어가 어둡게 운반한다.

규율 — 채도 예산

밝고 채도 높은 색은 정보 레이어 전용. 트랙·코어·배경은 어둡고 저채도 — 그래야 카테고리 dot이 떠오른다. 그라데이션·글로우는 절제(소프트 블롭 = 슬롭, 샤프 기하 = weaver).

밝음·채도↑ — 정보 전용 RESERVED

카테고리 4 · 코인 · 위협. 트랙/코어가 절대 안 쓰는 색.

어두움·저채도 — 무대 FIELD

트랙 = 중립 쿨화이트 / 코어 = 딥 엠버·틸·마룬 / 배경.

01

rev.2 → rev.3 — 같은 G 구조, 규율만

동일 G 합본. 바뀐 것 = 트랙 앰버→중립 쿨화이트 · 소프트 글로우 블롭 → 딥·기하 코어 · 흐름 앰버 대시 → 중립 트래블링 펄스. 카테고리 dot(🔵🔴)을 얹어 차이를 본다.

REV.2 — 정보색 오염

앰버 트랙 + 소프트 글로우

트랙 앰버가 🟡코인·🟡대공과 경합 → dot이 안 떠오름. 라디얼 글로우 블롭 = 무드 슬롭·기하 정체성 약함.

REV.3 — 정보 분리

중립 트랙 + 딥 기하 코어

트랙이 채도 0 → 🔵🔴 dot이 강하게 떠오름. 코어 = 딥 엠버 동심 다각형(트랙 형태 에코·어둠 유지). 펄스 = 중립 화이트.

02

권장안 — 3구역 정제 팔레트

트랙(쿨화이트)·펄스(중립)·코어 기하 = 구역 무관 동일 구조. 구역 정체성 = 코어 색만 딥·저채도로 교체. 전부 정보색과 분리.

03

흐름 패턴 — "살아 움직임"을 어떻게

전부 중립색·선 위·접선 방향(채도 0). 깜빡임 X(자동플레이감·위협 텔레그래프 혼동 회피). 주행 속도 동기.

04

코어 처리 — 그라데이션 재고

"소프트 글로우 그라데이션이 정말 어울리나?" → 디자이너 답 = 아니오. 샤프 기하가 weaver(Downwell·Geometry Dash). 절제 그라데이션은 깊이용으로만. 전부 딥·어둡게(위협 가독).

05

가독 게이트 — 정보색이 떠오르는가

권장(중립 트랙 + 딥 기하 코어 + 펄스) 위 전경: 정답 dot · 드론 · 가시 · 몬스터 · ⚪낙하물 · 코인. 채도를 비웠으니 정보색이 강하게 분리돼야 정상.

  • ✓
    트랙 = 채도 0 → 정보색 독점

    쿨화이트는 어느 카테고리도 아님. 🔵🔴🟡🟣·🪙·위협이 화면에서 유일한 채도 → 즉시 떠오름.

  • ✓
    코어 = 딥·저채도·중심·기하

    딥 엠버 동심 다각형. 위협 존(선 안쪽)에선 명도↓·밀도↓. 전경(L70%+)이 항상 코어 위로.

  • ✓
    위기 연출 = 트랙이 일시 붉게

    budget==1 시에만 트랙 펄스가 #FF5A5A 맥동(가장자리 한정). 평소 중립 → 위기 대비 극대화.

  • ?
    코어 명도·펄스 휘도 = 기기 후 잠금

    딥 색 정확 L값·펄스 밝기는 위협 기기 실렌더 1회 후 §9.1.6 확정.
