교습 6판 커리큘럼 — 어떻게 가르치고, 어떻게 넘어가는가

weaver는 별도의 핸드홀딩 튜토리얼이 없다. 첫 실행 = 동의 → 플레이 직행. 교습 6판이 곧 튜토리얼이며, 가르침은 화면 위 지시문이 아니라 레벨 설계 자체에 녹아 있다.

퍼즐 학습"이 몬스터엔 🔵 쓰세요" 같은 직접 지시·툴팁 없음. 몬스터 생김새(색·실루엣·거동)가 일관된 비주얼 언어 → 플레이어가 배워서 읽는다. 안전망(충돌 예산·반복 등장·일관 언어)이 실수해도 안 죽게 받쳐, 가르침이 곧 게임이 된다.

설계 원리 · 안전망

🪜 스캐폴딩

  • 한 번에 새 색 1개 — 인지 부하 분산 (P0→P4)
  • 단색 단일정답(각인) → 복수정답(워밍다운) — 처음엔 "이 색 = 이 무기" 1:1로 굳히고, 뒤로 갈수록 여러 무기로 풀리는 위협
  • 5–8 위협/판 — 충분한 반복으로 손에 익힘 (구 1동사 12판 = 판마다 온보딩 벽 → 폐기)
  • 전 슬롯 잠금 예고 — 다가올 무기를 숨기지 않고 잠금으로 보여줌

🛟 안전망 (anti-rage)

  • 충돌 예산 — 못 잡아도 즉사 X (하트 N, 교습 = 넉넉)
  • 반복 등장 — 같은 위협이 여러 번 → 틀려도 다음 기회
  • 일관 비주얼 언어 — 한 번 익힌 생김새 규칙이 끝까지 동일
  • 1.0x 고정 · 티켓 면제 — 속도/비용 압박 0, 진행 막힘 0
