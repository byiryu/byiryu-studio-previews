§2

모션 — 실제 구현 (라이브)

무기는 정적 데칼이 아니다. 자동슈터 표준 = 무기를 손 존에 두고 몸의 bob에 동기·타깃으로 조준·발사마다 반동. 아래는 그 모션의 개념 증명 (실제 run 스프라이트 + 무기 오버레이가 움직임) — 정확한 프레임별 좌표·반동 커브는 유니티 세션 튜닝.

run + bob 동기 · aim 스윕(정면↔상방) · recoil · 머즐플래시▶ 라이브 — 브라우저에서 재생
1

손 소켓 + 바디 bob 동기

무기 = 캐릭터 자식 "손 소켓"에 parent. run/idle/jump 의 수직 bob을 따라 무기도 같이 오르내림 → "몸에 붙어 살아있다".

design = 앵커 좌표 · plat = 소켓 트랜스폼 애니
2

타깃 조준 회전

자동사격이 유효 타깃 방향으로 무기를 grip pivot 중심 회전 (조준 입력 X). §4 회전 데모 참조.

plat = 런타임
3

발사 반동 (recoil)

발사마다 배럴 축으로 킥백 후 스냅 복귀 (DOTween). "쏘는 무게감".

plat = 런타임 커브 튜닝
4

머즐 플래시 + 투사체 VFX

발사 순간 머즐에 카테고리색 플래시 + 투사체/트레이서. 카테고리색을 정확히 운반하는 층 (스프라이트 글로우는 근사).

plat = 파티클·셰이더

§3

손 부착 — east 사이클 + 미러

§4

발사 회전 데모

자동사격은 조준 입력 없이 유효 타깃으로 발사 — 무기가 grip pivot을 중심으로 회전해 각도를 표현. 캐릭터 애니는 그대로. 벽 주행(§2.4) 시 = 캐릭터 전체가 트랙 접선으로 회전, 무기는 손에 붙은 채 함께 돈다.
