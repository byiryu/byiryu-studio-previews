weaver · design session · step 1 — 합의용

VFX · 타격감 무드 / 레퍼런스 보드

자동발사 게임에서 피드백 = 전투 감각의 유일한 통로. 이 보드는 최종 VFX를 판정하지 않는다 — 레퍼런스·룩 기준선·방향을 합의해서 step 2(VfxDef 룩 토큰 명세)로 넘어가기 위한 정렬판이다.

← weaver previews · spec §G · design PLAN M3(M2 step-1 선행) · 모션 = 룩 방향 개념일 뿐 — 타이밍·강도는 plat 기기 튜닝

왜 이게 "폴리시"가 아니라 "제품 그 자체"인가

weaver는 자동발사다. 플레이어가 직접 조준·발사하지 않으므로, "내가 위협에 영향을 주고 있다"를 느끼는 유일한 통로가 피드백(타격감·리액션·이펙트)이다. 투사체가 닿고 그냥 사라지면 — 게임이 무반응으로 읽힌다. (spec §G 위치 선언)

그래서 feel은 M6로 미룰 폴리시가 아니라 코어 동작이 생기는 마일스톤(M1 충돌·M2 명중)에서 1급으로 구현한다. MVP가 컷하는 건 이펙트 "종류 수"지 피드백 사슬의 존재가 아니다.

골든 룰 — "투사체가 적에 닿는 순간 화면이 반응하는가."

1 · 완성도 기준 바 (G3)

아래 ✅가 전부 충족돼야 "출시 가능". 하나라도 ❌면 출시 차단(spec §G3).

✅ 1급 (이게 기준)

  • 명중 = 버스트 + 히트스톱 + 피격 flinch
  • 처치 = 팝 / 기화 디졸브 / 링
  • 근접 = 슬래시 아크 + 무게(히트스톱) + 넉백
  • 피격 = 풀 피드백 사슬 [D] (silent 차감 금지)
  • 동시다발 = 캡으로 60fps 유지 + 가독

❌ 미달 (출시 차단)

  • 무반응 명중 (닿고 그냥 사라짐)
  • 즉시 Destroy() 처치 (연출 0)
  • 임팩트 0 근접
  • silent 피격 (하트만 조용히 깎임)
  • 폭주 시 프레임 드랍 / 화면 난장

2 · 레퍼런스 분해 — 무엇을 가져올 것인가

spec §G3 완성도 바 레퍼런스. 각 게임에서 weaver가 훔칠 정확한 한 가지를 사슬에 매핑한다. (스크린샷 대신 "가져올 룩 원리"로 — 저작권·정렬 목적)

Archero

자동발사 · 모바일 · 같은 장르
히트스톱명중 팝flinch

탄이 닿는 순간 아주 짧은 멈춤 + 적 흠칫(틴트 플래시). 자동발사인데도 "맞췄다"가 확실. weaver 🔵🟡 명중[A]의 직접 모델.

→ weaver

명중 = 버스트 + 히트스톱 ≤0.05s + 적 틴트 플래시. 자동발사 동족 레퍼런스 = 1순위.

Soul Knight

픽셀 · 다발 탄 · 셰이크
셰이크파편 팝다발 가독

탄·적이 많아도 마이크로 셰이크 + 작은 파편 팝으로 난장 없이 타격감 유지. 누적 캡으로 화면이 안 무너짐.

→ weaver

마이크로 셰이크(명중)·셰이크 강(충돌) + 누적 캡(동시다발 60fps 게이트). 픽셀톤 파편 = 기화 연출 톤 참고.

Vampire Survivors

초다발 처치 · 일괄 디졸브
처치 디졸브대량 가독색=정보

수십 마리 동시 처치를 가벼운 디졸브 + 색 코딩으로 처리. 무거운 파티클 0 — 모바일에서 폭주해도 읽힘.

→ weaver

처치 = 싼 기화 디졸브(VFX Graph 금지·스프라이트+DOTween). 동시다발에서도 색으로 "뭘 잡았나" 읽힘.

Downwell

제한 팔레트 · 색=정보 교과서
채도=정보대비절제

거의 흑백 위에 의미 있는 색만 빛난다. VFX가 화려해도 배경이 어두워 가독 1순위 유지. brief 핵심 정체성.

→ weaver

채도 = 정보 전용 규율(§9.3). VFX는 어둠 위에서만 빛난다 — 트랙·배경은 절대 채도 안 씀. paranoia #5/#6.

4 · VFX 룩 기준선 체크리스트 (art-reference 6층 패턴 답습)

캐릭터 아트가 6층 기준선(형태·깊이·글로우·juice·VFX·애니)으로 판정됐듯, VFX도 "있어야 할 층"을 먼저 합의한다. 이게 step 2 토큰의 채점표가 된다.

형태 언어 — 4 base가 구분되는가

버스트·방향·디졸브·링이 실루엣만으로 구별돼야. 같은 base를 위협·무기·처치가 재사용(§G4).디자인 SoT

글로우 / 블룸 — 어둠 위에서 빛나는가

다크 배경(#0C0C11) 위 발광 코어 + 헤일로. 단 채도=정보 규율 — VFX는 카테고리색을 운반, 배경은 침범 X.디자인 SoT

색 코딩 — 어느 무기/위협인지 읽히는가

🔵🔴🟡🟣 + 위기/피격 적색 분리. 동시다발에서도 "뭘 잡았나"가 색으로(Vampire Survivors 교훈).디자인 SoT

잔상 / 파편 — "기화" 테마 일관성

처치 = 캐릭터 death와 통일된 기화(흰 플래시→시안 픽셀 사방 흩어짐). 무게·파편 형태가 카테고리 성격 반영.디자인 SoT

타이밍 / 강도 — 히트스톱·셰이크·넉백

"닿는 순간 멈칫"의 길이·세기. 기기에서만 판정 — 종이/HTML로 확정 X (트랙면 교훈).plat 기기 튜닝

동시다발 — 폭주해도 60fps + 가독

풀링·누적 캡으로 프레임 유지 + 화면 난장 방지. 출시 하드 게이트(§G5·M7 차단 항목).plat 기기 게이트

5 · 4 base VFX 형태 언어 (G4 — 1 재생기 + 4 base)

추상화 재생기 1개가 4 base를 색·수명 데이터로 재사용(M5까지 4-case switch). 형태 방향만 합의 — 최종 파티클 craft는 plat Unity(Shuriken+스프라이트+DOTween).

버스트

BURST

방사 확산 + 페이드. 명중·머즐·처치 팝.

방향

DIRECTIONAL

축 방향 스윕. 슬래시 아크·넉백·트레일.

디졸브

DISSOLVE · 기화

상승 + 입자화 소멸. 전 위협 death 통일.

링

RING

확산 고리. 처치 강조·요격·경고·충격파.

카테고리별 명중 비주얼 방향 (4색)

같은 base를 색·형태로 카테고리 성격에 맞춤. 방향 제안 — step 2에서 정밀화.

🔵 원거리 = 점

날카로운 점 임팩트 — 작고 빠른 버스트. 정밀·연사감.

🔴 근접 = 아크

휘두르는 슬래시 아크 + 넉백 방향. 무게·범위.

🟡 대공 = 요격

상방 요격 폭발(링) — 공중에서 터짐. 낙하물 격추감.

🟣 특수 = 지글

지속 글로우 지글 — 빔 명중 지점이 끓음. 지속·관통.

처치 연출 3안 — "기화" 테마 (캐릭터 death와 통일)

전 위협 death = Unity 런타임 기화 디졸브(spec §6.8). 3가지 룩 후보 — 어느 쪽을 base로?

① 기화 디졸브 권장

흰 플래시 → 시안 픽셀 상승·흩어짐. 캐릭터 death와 동일 테마 = 세계 일관성. 싸고(스프라이트) 가독↑.

② 팝(burst)

순간 확산 파편. 가장 가볍고 다발 친화(Soul Knight). 단 "기화" 테마와 덜 통일.

③ 링(ring)

확산 고리 강조. 큰 처치/요격에 임팩트. 단발용 — 다발엔 과함.

→ 권장 = ① base + 큰 처치엔 ③ 링 가산. (step 2에서 위협 클래스별 매핑)

7 · 결정 항목 — step 2(VfxDef 룩 토큰)로 가기 위해

아래만 합의되면 step 2 = vfx_burst / vfx_dir / vfx_dissolve / vfx_ring + 카테고리·처치·적색 토큰을 design-system에 명세한다.

Q1 · 기준선

VFX 6층 기준선(§4) — 이대로 채점표로 잠글까?

특히 4·5층 분담(잔상/기화 테마=디자인 / 타이밍·강도=plat 기기). 트랙면 교훈 = 룩만 디자인 선행.

Q2 · 처치 base

처치 연출 base = ① 기화 디졸브(권장)?

캐릭터 death와 통일하는 ① + 큰 처치엔 ③ 링 가산 — 동의? 아니면 ② 팝 base?

Q3 · 카테고리 매핑

명중 비주얼 = 🔵점·🔴아크·🟡요격(링)·🟣지글 방향 OK?

같은 4 base를 색·형태로 변주 — 이 매핑으로 step 2 정밀화할까?

Q4 · 적색 분리

충돌/위기 #FF5A5A ⊥ 🔴 #FF6B6B 명도 분리 — step 2에서 잠금?

(옵션) AI 무드 레퍼런스 1~2장 생성해 룩 톤 정렬할지도 결정.
