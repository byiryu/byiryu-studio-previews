WEAVER아트 레퍼런스 — "진짜 게임" 기준선

코드 도형 스케치 중단. 출시된 실제 게임으로 "좋다/진짜다"의 기준선부터 맞춘다. 각 카드 = 게임명 + 왜 weaver에 관련 + 훔칠 기법 + 실물 이미지 링크(클릭 → 구글 이미지). 핵심 통찰: 미니멀이 리치해 보이는 건 "단순한 도형" 때문이 아니라 색 절제 + juice + 깊이의 craft 때문이다 — 내가 그동안 보여준 납작한 도형엔 그 craft 층이 없었다.

↺

왜 리셋했나. HTML 캔버스에 손으로 그린 단색 도형은 메커니즘 검증(스왑·회전·방향)엔 맞지만 아트 매력 판단엔 부적합 — craft 층(셰이딩·글로우·파티클·이징)이 없어 당연히 밋밋. 아래 게임들은 그 craft가 어디서 나오는지를 보여준다. 이걸 기준선으로 잡고 다음 단계(실제 아트 생성)로 간다.

A

미니멀이 "진짜 게임"으로 보이는 비결

단순 도형 + craft 층
Downwell2015 · Ojiro Fumoto이미지 →
흑·백·빨강 3색뿐인데 리치하다. 비결은 색이 아니라 juice — 화면 흔들림·히트스톱·파편·콤보 플래시.
훔칠 것: 색은 극단적으로 줄이되 발사·피격·콤보 순간의 연출에 모든 화려함을 몰아준다. "보상 순간만 화려"(우리 spec과 동일).
Geometry Dash2013 · RobTop이미지 →
캐릭터가 말 그대로 네모/도형인데 캐릭터로 읽힌다. 비결 = 얼굴 + 네온 글로우 + 트레일 + 회전 juice.
훔칠 것: 기하 캐릭터 정당성. 단 글로우·트레일·아웃라인 발광이 평면 도형을 "살아있게" 만든다 — 우리 둥근삼각에 결여됐던 층.
Thomas Was Alone2012 · Mike Bithell이미지 →
그냥 색깔 사각형들인데 성격이 폭발. 비결 = 부드러운 그림자/라이팅 + 모션 이징 + 내러티브.
훔칠 것: 소프트 섀도우 + 라이팅 + 이징. 평면 단색에 광원 하나만 줘도 "도형"이 "캐릭터"가 된다.
Super Hexagon2012 · Terry Cavanagh이미지 →
미니멀 기하 + 회전 + 강렬한 색 대비·펄스. weaver의 회전 트랙과 가장 가까운 비주얼 에너지.
훔칠 것: 회전·색 펄스·고대비로 만드는 긴장감. 정적 도형이 아니라 끊임없는 모션이 룩의 핵심.
B

무기를 "안 들고" 보여주는 법

손에 든 모델 X · VFX 정체화
ArcheroHabby · 모바일이미지 →
캐릭터는 자동 발사. 무기는 손의 모델이 아니라 발사체·궤적으로 존재. 펫/정령은 옆에서 오비탈로 떠다님.
훔칠 것: 우리 "플로팅 포드/이펙트" 방향이 장르 표준임을 검증. 단 포드가 입체·발광해야 함(납작 X).
Vampire Survivors2022 · poncle이미지 →
무기 정체성 = 전부 발사 패턴·색·VFX. 캐릭터는 작고 무기는 화면을 채우는 이펙트. 무기 = 화면의 주인공.
훔칠 것: 무기의 "와우"는 발사 이펙트에서 나온다 — 카테고리 4색 × juicy VFX. 우리 spec §2.5 "이펙트=BM 표면"과 정확히 일치.
Soul KnightChillyRoom · 모바일이미지 →
무기 종류 많지만 작게 들고, 머즐 플래시 + 발사체 색으로 무기 구분. 스왑이 빈번해도 안 헷갈림.
훔칠 것: 머즐 플래시 한 방으로 무기감·발사감 동시 해결. 카테고리색 머즐 = 즉시 가독.
Tomb of the MaskPlaygendary · 모바일이미지 →
네온 아케이드 + 벽 타기. weaver의 최근접 장르 레퍼런스(brief 기재). 캐릭터 작아도 네온으로 또렷.
훔칠 것: 네온 발광 + 트레일로 작은 캐릭터를 다크에서 띄우는 법. 벽 주행 가독의 실전 답.
C

회전·벽 주행에서 캐릭터 가독

weaver 고유 모션
VVVVVV2010 · Terry Cavanagh이미지 →
중력 반전. 단순 캐릭터지만 강한 실루엣 + 색으로 위아래 뒤집혀도 즉시 식별.
훔칠 것: 방향·중력이 바뀌어도 실루엣 + 색이 한결같으면 가독은 유지된다(우리 회전 우려의 답).
네온 아케이드 일반장르 무드이미지 →
다크 배경 + 발광 캐릭터/이펙트 = 모바일 아케이드의 "프리미엄" 룩 공식. 글로우가 저비용 고효율.
훔칠 것: 아우터 글로우 + 블룸. 같은 도형도 발광 처리 하나로 "진짜 게임"처럼 보인다.
★

기준선 — "진짜처럼 보이는가" 체크리스트

우리 아트를 이걸로 판정
합의할 품질 기준

도형이 아니라 이 6개 층이 "진짜 게임"을 만든다

내 캔버스 스케치가 가졌던 건 1번뿐(형태). 2~6이 통째로 빠져서 밋밋했다. 다음 아트는 이 6개를 충족해야 한다.

1

형태·실루엣

읽히는 캐릭터 형태 + 방향. 유일하게 있던 것.

2

깊이 (셰이딩·림라이트)

평면 단색 X — 광원·내부 음영·가장자리 발광으로 입체.결여됨

3

글로우·블룸

다크 배경에서 캐릭터·이펙트가 발광해 떠 보임.결여됨

4

juice (연출)

히트스톱·셰이크·파편·플래시·스쿼시 — 도형과 게임의 차이.결여됨

5

무기 = 발사 VFX

머즐 플래시 + 발사체 + 트레일을 카테고리 4색으로. 무기의 와우.결여됨

6

애니 craft

이징·기대·후속동작 — 선형 bob X. 살아있는 움직임.결여됨

다음기준선 합의 후 — 진짜 아트로

이 6개 기준에 동의하시면, 이건 손코딩 도형으론 못 만든다는 게 분명해진다 — 실제 아트 제작이 필요하다. 정공법 2-스텝:

① 캐릭터 아트 = AI 생성 (스튜디오 도구 ComfyUI/Recraft/Retro Diffusion, spec §2.5). 둥근삼각 컨셉 + 기준선 2·3을 프롬프트로 — 셰이딩·림라이트·글로우 입은 실제 스프라이트. 스왑 위해 본체 단색 키, 회전 위해 정면 비의존은 가이드로 유지.

② 무기·juice = Unity 런타임 VFX 패스 (4·5·6). 머즐 플래시·트레일·파티클·셰이크는 코드(절차적)지만 아트가 아니라 연출이라 이건 절차적이 정답. M0~M2 구현 시 셰이더·파티클로.

※ MVP-first 와의 균형: 캐릭터 1종 + 무기 4VFX 만 기준선 충족하면 출시 가능(스킨·정교화는 v1.x). 비용 = ComfyUI 무료(로컬) + 시간. 리드 전략 판단 대상.
