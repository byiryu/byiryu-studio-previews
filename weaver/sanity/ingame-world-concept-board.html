"허공"이 아니라 — 거대한 코어를 공전한다

현재 인게임 = 빈 다각형 위 달리기(허공). 제안 = brief의 "살아 움직이는 트랙"을 실현 — 비어있던 인테리어 32%(spec §2.4)를 공전 대상 코어로 채우고, 트랙을 선이 아닌 구조물로, 스폰을 세계에서 솟는 것으로. 중앙 큰 도형 = 플레이스홀더 (PixelLab 생성 대상, 최종 아트 아님) — 이 보드는 구도·층·무드·가독만 굳힘.

매체 게이트 #8: 코어·창조물·성운 = 코드로 안 그림 → 방향 확정 후 PixelLab. 보드의 그라디언트 블롭 = 자리·크기·읽힘 표시용 더미. 스타필드·트랙기하·펄스·VFX = plat 절차.

① 공전 코어 = 인테리어 32% 채움
플레이어가 도는 "그것". 잠든 리액터·거대 생물·붕괴 코어… 구역별 교체 = 배경이 곧 진행 서사. 회전 트랙에 *목적* 부여("왜 도나 → 공략하니까"). 제작 = PixelLab
② 트랙 = 구조물(달리는 림)
선 → 깊이 있는 림 + 림라이트 발광. 활성 무기 카테고리색으로 글로우. 에너지 펄스가 레일을 타고 흐름. 제작 = plat 절차/VFX
③ 세계에서 솟는 스폰
몬스터 = 코어 균열·헐 벤트서 기어나옴 / 낙하물 = 인테리어서 떨어짐 / 장애물 = 표면서 솟음(no-ceiling, 이미 spec). 세계가 위협의 출처 = 응집. 몬스터=PixelLab(완료) · 솟는 연출 =plat
④ 3층 패럴랙스
원경 성운(PixelLab)·스타필드(plat) / 중경 코어 / 근경 = 트랙 뒤로만 스쳐가는 실루엣(레인 침범 X). 깊이감.
⑤ 전경 = 풀대비 (가독 사수)
트랙면+위협만 고대비·풀채도. 배경(코어·성운)은 저주파·명도상한 아래 → 맥동해도 위협 실루엣 안 가림(paranoia #5).
