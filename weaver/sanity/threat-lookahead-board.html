전방 위협 미리보기 스트립 — 배치 3안

목적 = SwapWindow 보강(spec §4.7 결정 E). 카메라 단독 전방 시야 = 1.3~1.9s < 목표 2.5s → 코어 루프가 "반사신경·색맞추기"로 퇴화 위험. 스트립이 화면 진입 전 다가올 위협을 보여 스왑 시간을 벌어준다.
표시 = 위협 실루엣 + 머리 위 dot(카테고리 색 단서) + 도착 타이밍. 인게임 dot은 실제 위협에 이미 보이므로(입장 프리뷰만 dot 숨김 — §6.2) 스트립도 dot 표시 = 퍼즐 일관. 스트립 에셋 = 입장 프리뷰 재사용(신규 아트 0). 아래 토큰 도형은 레이아웃 placeholder — 실제 = assets/weaver/monster/ 스프라이트.

설계 노트 · 결정 항목

  • 왜 dot을 표시하나 — §6.2 퍼즐이 "생김새 추측"에서 "dot 색 보고 반응"으로 이동. 인게임 위협엔 dot이 이미 보이므로 스트립도 dot 표시 = 반응창 연장(입장 프리뷰만 dot 숨김 = 로드아웃 결정 유지). 스트립이 dot을 숨기면 거부된 "생김새 추측"을 강요 = 모순.
  • 읽기 방향 — 왼쪽(NOW/SOON, 임박) → 오른쪽(~2.5s 후). 위협이 우→좌로 흐르며 다가옴(캐릭터 기본 우향과 정합). 토큰은 도착에 맞춰 좌측으로 슬라이드.
  • 퇴화 방지 — 스트립은 SwapWindow 완화책이지 단순 색맞추기 유발이 아님. 깊이 = 로드아웃(어느 변형 챙길까) + 동시 다수 위협 + 변형 최적화(§6.2)에서 유지. ⚪(몸 회피)는 dot 없음 = "스왑 불요, 점프/슬라이드" 신호.
  • 추천 = B (하단·슬롯 직상) — ① 시선→엄지 루프 최단(스트립 🔴 → 직하 🔴 슬롯) ② 게임 영역 밖 = 위협 가독 침범 0(paranoia #5) ③ 손이 이미 있는 하단 존(paranoia #3). 트레이드오프 = 시선이 상단(액션)/하단(예고)로 분리되나, "예고 글랜스 → 선스왑 → 액션 주시" 순서로 자연.
  • 오클루전 가드 — A는 게임 영역 상단 오버레이라 HUD 3중 가드(풀폭 금지·캐릭터 클램프·침범 시 페이드)에 합류 필요. B/C는 게임 영역 밖이라 가드 불요(더 안전).
  • 표시 개수 — 동시 ~3개 권장(2.5s 분량). 4번째는 dim(예고만). 밀집 구간(겹침)은 토큰 겹쳐 쌓기 or "+2" 카운트.
  • 슬롯 cue 연동(선택) — 다가오는 위협 카테고리 슬롯에 미세 펄스(보드 🔴 슬롯). 강하면 자동 플레이감 → 약하게(opacity·glow만) 또는 생략. 결정 항목.
  • 제작 분담 — 디자인 = 스트립 토큰·레이아웃·dot 가독 룰(본 보드) / Unity 절차 = 위협 스폰 큐 → 스트립 토큰 인스턴스화·좌측 슬라이드·도착 동기. 스프라이트 = threat_preview 에셋 재사용.
