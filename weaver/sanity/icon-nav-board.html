4 · 무기고 아이콘 대안 (드론 패밀리 정합 — 결정 항목)

A · 교차검
design-system 명세값 · 보편 "무기고" 기호
✓ 기본 (토큰 정합)
B · 드론 코어
무기=동반 드론 정합(육각 셸+코어) · 단 "무기고" 인지 ↓
C · 블레이드+거치
무기 거치대 은유 · 다소 복잡
  • 무기고 아이콘 = A 교차검 권장(기본) — icon_nav 토큰 명세값이자 "무기고/로드아웃"의 보편 기호. 무기=드론 전환에도 "무기 보관·장착" 메타 의미는 검 아이콘이 가장 즉각. B(드론 코어)는 패밀리 정합엔 좋으나 "무기고"라는 *메뉴*로는 인지가 약함. A/B/C 택1 = 결정 항목.
  • 이모지 전면 교체 — wireframes·목업의 🎫🪙⭐ 같은 컬러 이모지도 점진적으로 모노라인 글리프 대체 권장(렌더 편차·톤 파괴 방지, design-system 원칙). 단 본 트랜치 스코프 = 내비·시스템 아이콘(인터랙티브 컨트롤). 통화·재화 칩 글리프는 별도 후속(스코프 가드).
  • 광고 제거 아이콘 — 광고 배너(둥근 사각) + 대각 슬래시 = "광고 없음". 보편 prohibition(원+슬래시)보다 "광고" 맥락이 읽힘. 메뉴 좌측 엣지 사이드 아이콘(보유 시 숨김).
  • 제작·핸드오프 — 전부 inline SVG(24 viewBox·stroke 1.8·round). plat = 이 path를 Unity Vector(또는 SVG 임포터/9-slice 불요)로 회수. 색은 코드에서 stroke만 지정(기본 #9AA0B0 / 활성 #EEEEF2 / 비활성 #556070) — 단일 마스터, 상태별 틴트.
  • 확정 후 = design-system icon_nav 에 SVG path 참조 추가 + 공통 아이콘 토큰(`icon_ui` 신설 검토) + wireframes 이모지 표기를 아이콘 참조로 교정.
