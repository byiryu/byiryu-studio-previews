컬러 몬스터 + 머리 위 dot 큐 — 1차 웨이브

수정 모델: 몬스터 = 자기 색·정체성 가진 개체(주인공처럼) · 정답 힌트 = 본체와 별개로 머리 위에 뜨는 dot(OR이면 여러 개). 본체색은 자유(4타입색에 안 묶임), 타입 정보는 dot이 운반. 측면 프로파일(> <). 개체·구조물·낙하물 다양.

🔎 핵심 확인 포인트 — "본체색 ≠ 정답, 머리 위 dot이 정답" 분리가 한눈에 읽히나? dot = 본체와 구분되는 밝은 글로우 마커(흰 테두리)로, 본체가 무슨 색이든 위에서 또렷이 뜸. (아래 데모: 같은 몬스터에 dot 1·2·3개 = OR)
