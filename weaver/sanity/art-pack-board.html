스타일 가드

선택·교체 팩이 반드시 만족할 기준
🔍

소형 렌더 실루엣 가독

트랙 위 캐릭터는 작게 그려진다. 내부 디테일이 작은 크기에서 뭉개지면 탈락 — 실루엣만으로 동작이 읽혀야 한다.

🎨

단일 본체색 = 스왑 키

본체가 하나의 교체 가능한 채움색이라야 스킨 8종 팔레트 스왑이 깨끗. 외곽선·AA 최소. 그라데이션/과한 셰이딩 금지 (≤8색).

🏃

측면·발바닥 접지 주행

모서리를 타고 달리므로 측면 뷰 + 바닥중앙 피벗. 탑다운·3/4뷰 부적합 (월드 고정 팬 카메라 — 옆벽도 측면 그대로 노출).

✨

이펙트 베이크 금지

글로우·트레일·점프 이펙트 = 코드 파티클 (스킨색 구동). 스프라이트는 본체만, 투명 배경. 효과가 구워진 팩은 스킨 시스템과 충돌.

🌑

톤 정합 — 절제된 중립

마스코트·귀여움 과잉 X. tense + minimal 무드 (brief). 또렷한 외곽선은 OK (소형에서 crisp). 색은 의미 있을 때만.

👾

적 3원형 실루엣 분리

지상(일반)·장갑(더 무거운 실루엣)·비행(공중) — 경고 링 색 = 카테고리(코드 오버레이)라 적 본체는 실루엣 구분 + 링 부착 여백만 만족.

⚖️

상업 가능 + 수정 허용

팔레트 스왑 = 수정. CC0 선호(재배포 가능). free-commercial 도 Private 레포 MVP 엔 허용. 바이너리 내 출처표기 강제는 회피(크레딧 화면까지만).

📐

규격 잠금 호환

아래 §C 규격(셀·프레임·피벗)으로 슬라이스 가능해야. 비정사각/불규칙 그리드는 임포트 시 재단 비용 — 잠금 규격에 맞춰 정규화 가능한지 확인.

▷ 권장 조합

플레이어 = C (rvros) · 적 = B (Pixel Adventure 2)

weaver의 핵심 동사 슬라이드는 좌버튼 전용 입력이다. 슬라이드·사망을 네이티브로 가진 건 C뿐 — 포즈팩(A)·hit only(B)에서 자작하면 MVP 일정 손해. 단일 본체 = 스킨 스왑 모델과 정확히 맞는다. 적은 C에 없으니 CC0 적 20종(B-PA2)으로 채운다.

리스크 점검 — C는 CC0가 아니라 원본 에셋 재배포 불가. weaver 레포 = Private 이고 게임 바이너리 내 사용은 라이선스가 명시 허용 → 무문제. 단 previews/마케팅에 원본 스프라이트시트 자체를 공개 호스팅하지 말 것. 어차피 MVP는 교체 전제(§2.5)라 노출 표면도 짧다.

대안 경로

순정 CC0 우선 — B 단독

법적 단순성·재배포 자유가 1순위면 B 단독(캐릭+적 한 팩). 비용 = 슬라이드·사망 자작 애니 2세트. 톤(둥근 캐주얼) 무드 검증 선행.

최소 미니멀 — A 단독

다크 미니멀 톤 정합·소형 가독은 A가 최고지만 애니 표면을 거의 전부 자작 → 1인 MVP 일정과 상충. 비권장(프로토 임시용엔 가능).

교체 단계 — 출시 후

다운로드 시그널 후 Retro Diffusion($20 일시불·완전소유) 또는 외주로 고유 캐릭터·스킨 라인업. §C 규격 그대로 → 코드 변경 0.
