03b

거동 모션 미리보기 — 발사 / 근접 (루프)

실 스프라이트 합성 · unity 런타임 거동 개념
🔵 발사 (원거리)
idle hover → 짧은 dash → 🔵 모듈 돌출 + 머즐 피크 → 투사체 발사 → 반동 → 스프링 복귀
🔴 근접 (블레이드 림)
idle hover → 전진 dash(적 근접) → 에너지 블레이드 림 아크 스윕 → 반동 → 복귀 (칼날 = 런타임 VFX)

⚠ 위 모션 = 개념 미리보기(CSS 합성). 실제 dash 커브·머즐 파티클·블레이드 아크 VFX·스프링 추종 = unity 런타임 (기기 판정 시제). 스프라이트 = 드론 베이스(hover) + 모듈만.

04

기기 판정 7항 (양산 하드게이트)

unity 시제 → 기기 1회 판정 → 통과 시 4모듈+근접 양산
1드론이 voyager 종속 — 2초점 거부 안 나나 (1화면 1주인공)
2dash–shoot–recoil–settle juice 살아있나
3발사 순간 카테고리 색 변별 (🔵🔴🟡🟣)
4코너/볼트 구간 화면 튐 0 (스무딩 헤딩 공유)
5P0~P1 발사 뜸할 때 존재감 (idle hover)
6드론 ↔ 낙하물 텔레그래프 미가림 (위치 실측)
7자동사격 판정 원점 = 캐릭터 일관성 (드론 = VFX 원점만)

  • 🔵 모듈 돌출 VFX 형태 레퍼런스
