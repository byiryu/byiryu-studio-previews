✅ 매체 게이트 #8 통과 — 도형 → 실물 · 공격 5 + 충돌 1 = 6종

CSS 도형엔 없던 craft 층(흰-핫 코어·네온 림·입자 모션·페이드 아크)이 살아있다. 공격 5종(🔵🔴🟡🟣+기화) + 충돌 1종([D] 적색) 전부 weaver 다크네온 톤 일관. 충돌 = 명중 스파크와 구분되는 거친 jarring 룩. 나머지 충돌 피드백(넉백·셰이크·진동·stagger) = Unity 런타임(에셋 아님 §G2).

6종 VFX — 피드백 사슬 / 카테고리 매핑

각 카드 = 실제 생성 모션(루프) + 9프레임 분해. 명중 4색·기화 디졸브(전 위협 처치)·충돌([D] player 피격).
