VFX 인게임 스케일 가독성 검증

"전체적으로 커보이지 않을까?" — 정당한 우려(paranoia #5). 무드 보드는 룩 보려고 크게 띄운 것. 여기선 실제 인게임 상대 크기로 몬스터·캐릭터 위에 올려 확인한다. 스프라이트 = 실제 스테이징 에셋(몬스터 96·캐릭터 88·VFX 64 캔버스).

← VFX 무드 프레임 · 스케일·밝기·지속 = 가독 룰(토큰)로 잠금 / 미세 튜닝 = plat 기기

스케일 기준 — VFX는 타깃보다 작거나 같게

캐릭터·몬스터 대비 VFX 권장 크기. 명중 = 피격 지점(작게) · 기화 = 몬스터 footprint · 빔 = 얇은 컬럼.

인게임 맥락 — 권장 스케일

다크 트랙 위 실제 상대 크기. 위협 실루엣이 VFX에 가려지지 않는다(처치 직전까지 읽힘).

왜 캡이 필요한가 — 권장 vs 과대

같은 🔵 명중을 같은 몬스터에. 과대(1.4×)는 위협을 덮어 "장식이 가독 해침 = 거부"(paranoia #5).

가독 룰 (토큰에 잠금)

design-system vfx_* — scale / readability

  • 크기 = 타깃 상대: 명중 ≤0.7× 몬스터 · 기화 =1.0× footprint · 슬래시 ≤1.2×(사거리) · 빔 폭 0.3× · 요격 ≤0.7× 낙하물. 절대 px 아님 — plat이 타깃 크기에서 파생.
  • 밝기·지속 캡: 명중/처치 = ≤0.4s 순간(잔상 남기지 않음) · 빔만 지속(얇게). "화면이 반응" = 짧은 플래시지 큰 持續 블롭 아님(§G3).
  • 동시다발 캡: 화면 내 VFX 인스턴스 상한 + 누적 셰이크 캡(§G5) → 폭주 시 가독·60fps 보존. plat 풀링/캡으로 검증(기기·하드 게이트).
  • 채도=정보: VFX만 채도↑(어둠·트랙은 저채도) → VFX가 곧 "여기 일어남" 신호. 위협 dot·실루엣은 VFX 위에서도 보이게 레이어 순서 보존.
